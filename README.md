# World-Bank-CO2-Emissions-Analysis
Interactive Tableau Dashboard tracking global CO2 emissions per capita and historical emission trends.

 🌍 World Bank CO2 Emissions Analysis (Tableau)

 📌 Project Overview
This project visualizes global carbon dioxide ($CO_2$) emissions and per capita emission patterns using World Bank datasets. The interactive dashboard helps identify top-emitting countries, tracks historical trends from 1960 onwards, and analyzes regional variations across the globe.

 🛠️ Tools & Technologies
- **Data Visualization Tool:** Tableau Desktop / Tableau Public
- **Data Source:** World Bank Development Indicators ($CO_2$ Emissions Dataset)
- **Visuals Included:** Interactive Map Visualizations, Historical Line Charts, Regional Trends

🔑 Key Insights & Analytics
- **Geographic Mapping:** Interactive symbol map displaying emission concentrations across different regions (e.g., South Asia, North America).
- **Total Emissions Over Time:** Historical tracking of total $CO_2$ output ($kt$) across major economic hubs.
- **Per Capita Emissions:** Evaluation of $CO_2$ metric tons per person to understand individual carbon footprints per country.
- **Interactive Region Filter:** Allows filtering by specific geographic regions to evaluate localized trends.
